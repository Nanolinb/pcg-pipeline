## 2026-11-13 · 廊桥（Skybridge）标准组件与连接生成

### 数据与生成
- 新增 `PCGSkybridgeConnector` 结合点（建筑 + 立面边 + 边内位置 + 楼层）与 `PCGSkybridgeDefinition` 廊桥定义（路径节点 + 每节点转弯强度 + 自动错开抬升），全部持久化为 plan 生成数据，纳入语义摘要与撤销快照。
- 新增 `PCGSkybridgeGenerator`：三次 Hermite 样条采样扫掠标准组件横截面成桥；起止楼层不同自动生成坡道，节点拖拽与转弯强度编辑实时重建。
- 新增标准组件 `skybridge_basic.tres`（角色 `SKYBRIDGE`、几何 `SKYBRIDGE`）：横截面单元含薄桥面（0.08m）、双侧扶手横档与出挑顶棚，结构/扶手双材质槽；支撑顶棚的立柱沿桥长按 1.6m 等距独立布置（数量随桥长增加、两端必有），侧面保持镂空；生成器沿路径逐件扫掠，相邻件嵌入避免共面闪面。
- 配色规则：廊桥基础色取两端建筑墙色的中间色，桥面略深、扶手提亮、顶棚加深，同色系和谐；替换建筑配色后廊桥自动跟随。
- 立面自动适配：结合点所在楼层与开间从立面边挖除，剩余区间重新均匀排窗，入口被占时自动挪到最大自由区间。
- 门洞交接：结合点立面自动裁切内凹门洞（宽 = 结合点宽 + 0.3m，深 0.45m，墙面分条 + 五面洞道，主体保持封闭流形）；门套（portal）由廊桥组件在桥两端生成，随廊桥出现/消失与替换，建筑侧只裁切不放组件；桥端伸入洞道与楼板齐平。默认结合点宽 1.2m。
- 交叉求解：平面投影相交的廊桥按横截面高度重叠比例判定——超过 60% 合并为一个 cross 交叉结构（双方向交汇盒），否则 ID 较大者自动垂直错开并保留 0.6m 净空，抬升量留在生成数据中可继续微调。
- 工作台新增廊桥模式：平面编辑 / 标注结合点 / 桥节点编辑三种顶视图交互，结合点楼层、生成廊桥、删除廊桥、转弯强度与桥面高度调节，顶视图绘制结合点、桥路径、节点高度与错开标记。
