# PCG 建筑群编辑系统 · v0.15.1 修复说明

发布日期：2026-11-02  
状态：崩溃修复与自动验收完成，等待用户验证。

## 修复问题

在 Godot 编辑器中切换资产任务时，热重载新增 UV/碰撞字段可能使已有任务对象的枚举字段短暂为 `Nil`。校验器直接对类型化数组执行 `has`，触发 Godot 错误并可能最终崩溃。

实际日志：`reports/baseline/editor_gui_v0.15.log`。

## 修复内容

- 类别、生产者、精度、状态、UV 和碰撞策略在校验前统一归一化为 StringName。
- 热重载中的空字段只产生可定位的校验错误，不再进入引擎崩溃路径。
- 新增空字段专项回归。
- 新增四个正式示例逐一选择和校验回归，确保任务切换路径持续受控。

## 验证

- 资产任务模型：48 项通过。
- 资产任务窗口及正式示例选择：39 项通过。
- 完整 `tools/run_gate.sh` 通过。
- 修复后 Godot 资产任务窗口可正常打开；自动下拉点击未可靠生效，因此不声称额外 GUI 点击流通过。
