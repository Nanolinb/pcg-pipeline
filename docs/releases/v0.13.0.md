# PCG 建筑群编辑系统 · v0.13.0 版本说明

发布日期：2026-10-29  
状态：已完成开发与自动/本机图形验收，等待用户验证。  
腾讯文档空间：[PCG 建筑群编辑系统](https://docs.qq.com/space/DZWNhamhvUGtoQmRJ)（内含本说明的原始 Markdown 文件）。

## 本版本目标

完成大型建筑群 PCG 编辑系统的第一个集成基线：保护现有功能、建立可重复回归、验证共享内核载体，并冻结下一版本公共契约。本版本不包含建筑样本生成器或城市群布局功能。

## 主要交付

### 1. 安全版本管理

- 建立 `v0.12.0-baseline` 保护标签。
- 原有 PipeWeaver 材质工作、自动回归、规划基线、共享内核 Spike、契约和图形证据分别提交。
- 两个工程统一升级为 `0.13.0`，发布提交带 `v0.13.0` 标签。
- 后续问题按功能提交进行 `git revert` 和差异检查，不依赖覆盖工作区或破坏性 reset。

### 2. 双工程自动回归

- 根工程 smoke 从主场景解耦，保留原 `--smoke-test` 和独立测试入口。
- PipeWeaver 新增 56 项真实生成断言，覆盖路径、管体、接头、内存重编辑和 Chunk 合批。
- 修复同材质多 Surface 合批时的顶点串用，使用 `surface_index + old_index` 去重。
- `tools/run_gate.sh` 统一检查版本、双工程 smoke、共享包冷导入，同时检查退出码和 PASS 标记。

### 3. 共享内核载体

- 独立来源：`shared/addons/pcg_shared/`。
- 根工程、PipeWeaver、最小第三消费者通过相对目录链接加载同一模块。
- 三个消费者在一次性副本中完成无 `.godot/` 缓存的重导入。
- 验证无重复核心类名、UID、Autoload 和插件缓存冲突；断链阴性对照真实失败。
- 本版本只完成 Spike，没有全量迁移两个主程序的现有核心代码。

### 4. v0.14 公共契约

`docs/core_contracts.md` 已冻结：

- 稳定 ID、格式版本和迁移。
- 编辑命令与 UndoRedo。
- 确定性随机流。
- 表面宿主接口。
- 规范化序列化与重建签名。
- 原子保存、轮换备份和恢复。
- 共享包与 PipeWeaver 快照适配边界。

### 5. 本机图形证据

- 根工程真实输入 smoke 通过，G0 拱形窗截图已归档。
- PipeWeaver 自定义 BaseColor 填入、清除回退和界面重编辑通过，G1 截图已归档。
- 根工程即时视觉日志为 116 FPS、拖动 115 FPS，仅作参考，不等同于 30 秒中位数/P95 性能统计。

## 已知限制

- 根工程退出时仍有既有 Dummy Renderer / GLES RID 清理警告，本版本未将其误报为已修复。
- 共享目录符号链接已在 Godot 4.6.2 / macOS 验证；Windows 需要后续复测或显式链接步骤。
- 当前 PipeWeaver 快照仍是内存重编辑数据，不是磁盘快照格式。
- 尚未开始 v0.14 正式核心迁移、资产任务单或建筑样本工作台。

## 用户验证建议

1. 执行 `tools/run_gate.sh`，应看到全部 headless 检查通过。
2. 根工程运行 `-- --smoke-test`，确认真实输入回归通过。
3. 根工程运行 `-- --visual-check`，检查拱形窗与过渡。
4. 打开 PipeWeaver，在 PBR 面板填入 BaseColor，确认管体变化；清除后确认默认恢复。
5. 完成当前管道，进入选择模式并重新编辑，确认控制点恢复。

## 回滚方式

- 仅检查旧版本：切换到 `v0.12.0-baseline` 的只读工作树或新分支。
- 修复当前版本：优先定位功能提交并使用 `git revert`，保留之后的其他工作。
- 不在包含未验证修改的工作区中直接 reset。
