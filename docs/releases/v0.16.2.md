# PCG 建筑群编辑系统 · v0.16.2 修复说明

状态：测试资产绕序修复与发布流程验收完成，等待用户验证。

## 用户问题

用户加载 `res://assets/raw/valid_crate.tres` 后，“发布”保持灰色。报告明确指出有向体积为正，且平面试装未通过。

发布按钮被禁用是正确的安全行为，不能绕过验收。

## 根因与修复

- 测试夹具生成器误将数学逆时针当成 Godot 正面，导致有向体积符号错误。
- 修正四边形与三角形的绕序判断。
- 交换 ±Z 面错误的方向提示，消除四个不一致三角。
- 重新导出全部六份测试资源。
- 新增正式原始 `valid_crate.tres` 从真实加载按钮到校准、试装、发布和重载的完整回归。

## 验证结果

- 单位箱体源有向体积：`-1.000000`。
- 校准后有向体积：`-0.216000`，与 0.6m 边长一致。
- 平面、圆柱、半球圆柱试装全部通过。
- 正式标准资产与全部 Mesh 文件发布、重载成功。
- L1 窗口测试：115 项通过，0 失败。
- 非 headless `--capture` 同样通过，新增 `02c_valid_crate.png` 证据。
