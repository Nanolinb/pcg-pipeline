# PCG 建筑群编辑系统 · v0.16.1 修复说明

发布日期：2026-11-02  
状态：窗口裁切修复与发布验收完成，等待用户验证。  
腾讯文档空间：[PCG 建筑群编辑系统](https://docs.qq.com/space/DZWNhamhvUGtoQmRJ)。

## 修复问题

用户反馈“资产标准化”窗口菜单显示不全，无法看到加载按钮。实际原因是窗口内容缺少完整滚动布局，且加载按钮挤在候选资源行右侧，窄窗口下被裁切。

## 修复内容

- 根内容加入覆盖窗口的 ScrollContainer，支持横向和纵向访问。
- 加载操作改为独立、完整宽度的“加载资源”按钮。
- 长任务名称允许截断，避免撑大最小内容宽度。
- 校准、试装、报告、发布和重载均可通过滚动访问。
- 增加 620×640 小窗口布局、按钮可见性、滚动和真实按钮加载回归。

## 验证结果

- L1 窗口测试：93 项通过，0 失败。
- 非 headless `--capture`：93 项通过，六张阶段截图已更新。
- 完整 `tools/run_gate.sh` 通过。
- 已人工检查截图：加载按钮完整可见；发布目录、发布和重载按钮可访问。

报告：`reports/release_verification/v0.16.0/README.md` 已同步补充修复结果；截图目录不变。
