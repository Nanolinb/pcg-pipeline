# PCG 建筑群编辑系统 · v0.15.0 版本说明

发布日期：2026-11-02  
状态：可见功能与自动验收完成，等待用户操作验证。

## 本版本成果

这是一个可在 Godot 编辑器中直接操作的功能版本，不只是文档或测试基础设施。

新增 **“L0 资产任务与精度规范”窗口**，用于在人工、外部工具或 AI 开始生产前，填写、校验和保存标准化资产任务单。

## 如何打开

1. 用 Godot 打开根目录 `project.godot`。
2. 在检查器中的“表面组件”面板顶部点击 **“资产任务”**。
3. 在弹出的窗口中选择现有任务，或点击“新建”。
4. 填写任务内容，查看校验结果，保存到 `assets/tasks/`；点击“重开”可丢弃未保存修改并从磁盘恢复。

也可使用验收参数启动编辑器自动打开窗口：

```bash
/Applications/Godot.app/Contents/MacOS/Godot --editor --path . -- --asset-task-gui-check
```

## 可见功能

- 现有任务选择、新建、保存、重开。
- 类别、名称、用途、风格标签和参考链接。
- 目标尺寸、尺寸上下限、原点、轴向和根部嵌入。
- 安装面、连接口、固定特征、可变外观和禁止特征。
- 近景/中景/远景精度档位。
- LOD0/1/2 三角预算、贴图尺寸、材质预算。
- UV 策略和碰撞策略。
- 人工、AI、外部、程序来源及溯源信息。
- 多候选引用，不覆盖来源工具、提示词、种子和版本。
- 草案、已指派、候选、待验收、已发布、已拒绝状态。
- 校验失败定位到具体字段，非草案任务不满足分配条件时禁止保存。

## 范围边界

- 本版本不执行 Mesh 修复、候选生成或几何验收；这些属于后续 L1。
- 本版本不生成建筑样本或城市群。
- 候选引用允许指向尚未落盘的文件，其存在性在候选生产阶段校验。
- 共享目录链接已在 macOS / Godot 4.6.2 验证，其他平台需单独复测。
- 根工程仍有既有退出清理警告，未计为已修复。
