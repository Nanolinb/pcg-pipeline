# PCG 建筑群编辑系统 · v0.16.0 版本说明

发布日期：2026-11-02  
状态：L1 可见工具与自动验收完成，等待用户操作验证。  
腾讯文档空间：[PCG 建筑群编辑系统](https://docs.qq.com/space/DZWNhamhvUGtoQmRJ)。

## 本版本成果

新增可在 Godot 中操作的 **“L1 资产标准化与验收”窗口**，把候选 Mesh / PackedScene 转成带几何、材质、LOD、碰撞和占用数据的正式标准资产。

## 如何打开

1. 打开根目录 `project.godot`。
2. 在检查器“表面组件”面板顶部点击 **“资产标准化”**。
3. 选择 L0 任务，输入 `res://assets/raw/valid_crate.tres` 或其他 Mesh/PackedScene 路径。
4. 加载并查看验收报告，执行校准和三主体试装。
5. 设置净空与视觉保护区，生成白盒/碰撞/LOD。
6. 硬性检查通过后发布，再执行重载核对。

测试资源位于 `assets/raw/`，包含有效、开放、退化、缺 UV 和非流形示例。

自动打开窗口的验收命令：

```bash
/Applications/Godot.app/Contents/MacOS/Godot --editor --path . -- --asset-standardization-gui-check
```

## 主要功能

- 零面积面、开放边、非流形边、法线、UV0、材质和预算检查。
- 尺寸、原点、轴向、根部嵌入与安装面校准。
- 平面、圆柱、半球圆柱试装，检查反转、漂浮和穿背。
- 白盒、Box/Convex/Concave 碰撞输出与明确层/掩码。
- 实体、嵌入、禁入、净空和视觉保护五类 AABB。
- 真实 LOD 减面或显式 LOD；直通与不可达目标必须披露。
- 标准资产包含稳定 ID、任务/来源、Mesh、材质 Profile、验收报告和 LOD。
- 原子发布到 `assets/published/`，清单与每级 Mesh 可重载；缺依赖或重复 ID 会拒绝。
