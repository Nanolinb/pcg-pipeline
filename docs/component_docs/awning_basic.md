# 布艺遮阳棚（awning_basic）

## 目标

为立面窗户提供布艺遮阳棚装饰。

- **资源**：`assets/building_components/awning_basic.tres`，角色 `AWNING`，几何 `AWNING`，尺寸 1.35 × 0.07 × 0.85 m。
- **坐标约定**：+Z 朝外，原点为墙面安装中心；由对应窗户位置和宽度派生。
- **宿主规则**：装饰记录宿主窗户槽位，只有宿主窗户通过占用检查后才生成；参与 AABB 占用、凹角/转角深度净空和其他建筑实体相交检查。
- **支撑结构**：两侧斜撑从墙面低点连接至棚体外缘，不允许悬空支撑。
- **联动**：宿主窗户不合法时，其遮阳棚一并阻止生成。
