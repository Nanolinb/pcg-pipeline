# 标准入口门（door_basic）

## 目标

为每栋建筑提供地面层入口组件。

- **资源**：`assets/building_components/door_basic.tres`，角色 `DOOR`，几何 `DOOR`，尺寸 1.1 × 2.05 × 0.14 m，框架宽 0.12 m。
- **材质槽**：第一表面门框（`building/door/frame`），第二表面门板（`building/door/panel`）。
- **坐标约定**：同立面组件，+Z 朝外，原点为墙面中心；默认位于最长立面的地面层。
- **选址规则**：入口从满足角点净空和相邻建筑净空的立面候选中选择，可被 `use_double_entrance` 显式替换为双门入口；入口在立面求解中优先预留。

## 修改记录

### 2026-11-13 · 平面驱动建筑复现原型
- 首批六个建筑标准组件之一；门框使用封闭矩形环。

### 2026-11-13 · 建筑装饰冲突修复与选中建筑修复
- 入口改为从满足角点和相邻建筑净空的立面候选中选择。

### 2026-11-13 · 门窗纳入选中建筑修复
- 入口优先预留纳入统一立面求解。
