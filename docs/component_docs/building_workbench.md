# 建筑平面工作台（building_workbench）

## 目标

提供平面驱动的建筑编辑工作台（`scenes/building_workbench.tscn`，主场景经“打开建筑平面工作台”按钮进入），让用户在顶视图上以生成数据的方式编辑建筑群。

- **主体编辑**：顶点拖动、面岛新增/切分/删除、整栋平移（保留稳定 ID、单次撤销、同步依赖连接）、相交/相接轮廓融合（保留主选中 ID 和最高楼层）；存在未处理廊桥连接时切分/融合明确拒绝。
- **参数编辑**：楼层、层高、细节种子（数值修改后立即自动应用）、墙面颜色；`wall_panel_width`（工程默认 1.75 m）与 `wall_panels_fused` 开关同样可编辑，纳入撤销/重做快照。
- **视图**：顶视图空白/右键/中键平移，25%～800% 光标中心滚轮缩放与一键适配；主 3D 视图中键拖动沿相机平面平移、右键环绕、滚轮调整距离；独立原生细节窗口与原视图共享选择、模式、数据和编辑历史。
- **模式与选择**：左侧分“建筑主体编辑”和“廊桥编辑”两组；Shift+单击多选，融合严格使用显式选中集合，不满足条件时按钮灰色并给出原因。
- **生成**：新建建筑按确定性随机流生成尺寸、矩形/L 形轮廓、楼层、种子、轻微旋转和颜色，在建筑群外围及空隙采样 32 个候选并按密度评分选址。
- **地形**：平面文档支持坡度；建筑按轮廓最高点建立水平基准面，低侧生成封闭基础，坡面平移自动更新标高。
- **修复**：“修复选中建筑”只重建当前建筑，重排门窗并报告阻止的立面组件数量。
- **数据边界**：建筑平面、楼层和材质参数始终保留为生成数据；撤销、重做和保存所需输入均为 Resource 数据，不依赖生成的 NodePath。

## 修改记录

### 2026-11-20 · 墙板参数与融合/预览切换（P0 切片）
- 参数编辑新增 `wall_panel_width`（工程默认 1.75 m，非美术冻结模数）与 `wall_panels_fused`（默认 true）开关；二者纳入撤销/重做快照与 semantic_data。
- 切换只影响显示与派生墙板布局：fused 保持 DerivedSolid 单一融合显示，unfused 显示按 slot 分组的 WallPanels 预览节点；平面图、组件、connector/廊桥与稳定 ID 不变。
- 单元预览以细缝辨认边界；右侧参数区仅纵向滚动，避免横向裁切。真实输入回归覆盖预览、模数输入、确认融合与撤销。
