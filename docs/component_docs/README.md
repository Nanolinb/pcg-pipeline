# 组件文档

每个组件一份文档，供腾讯文档空间「PCG 建筑群编辑系统」同步使用：<https://docs.qq.com/space/DZWNhamhvUGtoQmRJ>

## 结构约定

每份文档固定两节：

1. **## 目标**——组件要达成什么样的目标，含完整功能解释（资源、坐标约定、规则、与其他组件的关系）。
2. **## 修改记录**——按日期追加；某次修改明显改变目标时，同步修订上面的「目标」一节（如 `roof_drying_rack_basic.md` 的“目标修订”写法）。
