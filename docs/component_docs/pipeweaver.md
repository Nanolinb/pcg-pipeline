# PipeWeaver 管道工具（PipeWeaver）

## 目标

独立工程（`PipeWeaver/project.godot`）的管道生成工具：在主体表面绘制、编辑并固化管道。

- **路径**：表面起止点 A* 寻路；起止点可跨两个不同主体，以“起点表面长度 + 跨接距离 + 终点表面长度”最短为准；Paint 模式可跨面一笔绘制并在现有管道上点击插入控制点。
- **编辑**：控制点拖动/插入/删除、每节点角度、硬直角与独立圆角分段、每节点 `wall_offset` 离墙偏移（0～3 m）、撤销；选择模式支持单选恢复编辑、Shift/开关多选和全选。
- **棱边响应**：起止、Paint、手动插入和拖动统一在路径重建时检测同主体法线突变，超过 45° 自动插入棱边控制点，默认硬转角和接头，已有硬转角跳过。
- **网格**：连续管体、正确法线、世界尺度 UV、直径分段和自动接头；自适应网格按相邻路径方向和表面法线识别长直段减面（默认直线步长 4 倍贴图世界尺寸，弯道 0.28 倍）；冻结后按 8 m 空间 Chunk × 材质合批为固定 Mesh，保留 PCG 数据可重选恢复编辑。
- **材质**：程序 PBR 可平铺纹理（Base/Detail/Detail Normal/ORM），共享材质库管理；每管独立材质快照；归一化 UV2 专用于每管 AO 烘焙。
- **预设库**：`PipePreset` 目录加载（工业水气、高压蒸汽、铜质燃气、PVC 排水、线缆护套 5 种样本），选中预设替换当前或全部选中管道，保持路径与控制点不变，多选批量替换不增加完成计数。
