# 标准木框窗（window_basic）

## 目标

为建筑立面提供默认的木框窗组件，是立面开窗的标准答案。

- **资源**：`assets/building_components/window_basic.tres`，角色 `WINDOW`，几何 `FRAME`，尺寸 0.95 × 1.2 × 0.12 m，框架宽 0.1 m。
- **材质槽**：第一表面框架（`building/window/frame`），第二表面玻璃（`building/window/glass`），顺序固定不可调换。
- **坐标约定**：XY 为立面，+Z 朝外，原点为墙面上的组件中心；按立面开间和楼层居中布置。
- **立面求解**：与入口门、遮阳棚等装饰进入同一占用与角点求解；不合法的窗户不生成，且不再派生其阳台、晾衣杆或遮阳棚。

## 修改记录

### 2026-11-13 · 平面驱动建筑复现原型
- 首批六个建筑标准组件之一；窗框使用封闭矩形环而非相接盒体，框架/玻璃双材质槽体系在此建立。

### 2026-11-13 · 门窗纳入选中建筑修复
- 入口优先预留，窗户和装饰随后进入同一占用与角点求解；修复按钮可重排门窗并报告阻止的立面组件数量。
