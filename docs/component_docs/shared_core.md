# 共享内核（pcg_shared）

## 目标

两个工程（根工程与 PipeWeaver）共用的公共内核插件（`addons/pcg_shared/`），保证核心能力只有一份物理来源。

- **契约能力**：稳定 ID、格式迁移、编辑命令、确定性随机流、重建签名、原子保存和三类表面宿主接口。
- **共享方式**：根工程、PipeWeaver 和第三消费者通过相对目录链接使用同一物理来源，禁止双向复制同步；无 `.godot/` 缓存冷导入无重复类名、UID、Autoload 或插件缓存冲突。
- **共享内容**：Material Profile、编辑命令与确定性随机、规范化签名、表面宿主接口；2026-11-14 起新增共享网格原语、表面数学、共享类解析器与 JSON 文档骨架，移除多份重复实现。
- **边界**：PipeWeaver、CSG、领域资源和主程序保持独立，不为减少行数强行合并；共享链接一致性由 `tools/check_architecture.py` 门禁检查。
