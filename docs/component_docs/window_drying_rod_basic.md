# 窗外晾衣杆 · 空杆（window_drying_rod_basic）

## 目标

为上层立面窗户提供窗外晾衣杆（无衣物版本）。

- **资源**：`assets/building_components/window_drying_rod_basic.tres`，角色 `WINDOW_DRYING_ROD`，几何 `WINDOW_DRYING_ROD`，尺寸 1.35 × 0.12 × 1.0 m。
- **坐标约定**：XY 为立面，+Z 朝外；由上层窗户派生，与有衣物版本共用安装角色。
- **占用规则**：参与装饰 AABB 占用、凹角/转角深度净空检查；宿主窗户不合法时不生成。

## 修改记录

- 新增组件；空杆与有衣物版本共享角色，按建筑独立随机流稳定装配。

### 2026-11-13 · 建筑装饰冲突修复与选中建筑修复
- 纳入 AABB 占用与凹角净空检查，记录宿主窗户槽位。
