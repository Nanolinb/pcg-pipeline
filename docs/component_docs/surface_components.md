# Surface Component 编辑器插件（surface_components）

## 目标

根工程默认启用的 EditorPlugin（`addons/surface_components`），在 Godot 编辑器内把标准组件吸附到主体表面并完成融合。

- **主体**：可直接创建平面、圆柱、半球圆柱（上半球 + 下半圆柱封闭 CSG 并集）三类吸附主体，主体随场景保存。
- **组件库**：拱形窗、圆窗、方窗拖放放置；提供主体高亮、吸附放置、选中移动、橙色角度手柄（-90°～90° 法线倾角）与绿色等比缩放手柄。
- **过渡包裹**：每个组件可开关主体包裹过渡；厚度按组件 footprint、缩放和主体曲率自适应；弧度 -1～1（0 直线斜面，正值凹圆弧，负值反向圆弧）；圆窗为根部大外沿小的封闭梯形圆台。
- **融合与显示**：实时 CSG 融合或后合并轻量预览（单组件合并/全部合并）；最终显示按 8 m Chunk × 材质合批，保留 smooth groups、法线和 UV0；UV2 重心坐标水密线框。
- **密度与性能**：过渡精度 25%/50%/100%/200% 与 LOD 0/1/2；过渡 Mesh 按签名缓存、CSG 延迟提交与 0.1 s 刷新节流（拖动约 17→39 FPS）。
- **材质**：Material Profile（BaseColor、Detail、Normal、ORM 四贴图槽 + Tint/粗糙度/金属度），通用贴图槽面板支持填入与清除回退，变更仅刷新共享材质。
- **资产层**：L0 资产任务工作台（任务选择、新建、校验、保存、多候选引用）；v0.16 L1 资产标准化窗口（加载、几何验收、尺寸/轴向校准、三主体试装、白盒/碰撞/LOD、JSON 清单原子发布）。
