# 廊桥连接系统（skybridge_system）

## 目标

在建筑群之间生成廊桥连接，是 plan 级生成结构：不绑定单栋立面，由结合点与廊桥定义驱动，复用标准组件体系。

- **数据模型**：`PCGSkybridgeConnector` 结合点（建筑 ID + 立面边序号 + 边内位置 + 楼层），`PCGSkybridgeDefinition` 廊桥定义（持久路径节点 + 每节点 `tension` 转弯强度 + `auto_lift` 自动错开抬升），全部持久化为 plan 生成数据，纳入语义摘要与撤销快照。
- **生成**：`PCGSkybridgeGenerator` 沿三次 Hermite 样条采样扫掠标准组件横截面成桥；起止楼层不同自动生成坡道；节点拖拽与转弯强度编辑实时重建。
- **立面适配**：结合点所在楼层与开间从立面边挖除，剩余区间重新均匀排窗；给建筑生成器提供立面避让区。
- **门洞交接**：结合点立面自动裁切内凹门洞，洞口放门套组件，桥端伸入洞道顶住背板，桥面与建筑楼板齐平。
- **交叉求解**：平面投影相交的廊桥按横截面高度重叠比例判定——超过 60% 合并为一个 cross 结构（双方向交汇盒），否则 ID 较大者自动垂直错开并保留 0.6 m 净空；判定只依赖生成数据，重建结果确定。
- **编辑**：平面编辑 / 标注结合点 / 桥节点编辑三种顶视图交互；结合点楼层、生成、删除、转弯强度与桥面高度调节；顶视图绘制结合点、桥路径、节点高度与错开标记。
- **联动**：主体平移时结合点跟随；结合点高度包含主体地面标高，廊桥随两端更新；存在未处理连接时切分/融合明确拒绝。

- 节点增加 `in`/`out` 手柄（相对偏移向量，3× 导出 Hermite 切向量），顶视图可视化并可拖拽；无手柄退回 tension，设置 tension 清除手柄；手柄纳入语义摘要与撤销快照。
