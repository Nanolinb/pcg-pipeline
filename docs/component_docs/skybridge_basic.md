# 标准廊桥（skybridge_basic）

## 目标

为建筑群之间的连接提供可扫掠成桥的标准廊桥组件。

- **资源**：`assets/building_components/skybridge_basic.tres`，角色 `SKYBRIDGE`，几何 `SKYBRIDGE`，尺寸 2 × 3 × 1 m（桥宽 2 m，桥面到顶棚顶总高 3 m，Z 为 1 m 切片厚度），框架宽 0.1 m。
- **坐标约定**：横截面定义在局部 XY 平面（X 桥宽、Y 以桥面为 0 向上），Z 为 1 米切片厚度；`size.y` 即桥面到顶棚顶的总高。
- **部件分组**：`skybridge_part_groups()` 输出六组参数——`frame`（沿桥连续扫掠的结构件，如桥面）、`accent`（两侧扶手横档）、`roof`（出挑顶棚）、`post`（顶棚立柱 size/center_y/spacing，默认 1.6 m 等距）、`baluster`（两侧栏杆立柱）、`portal`（桥端门套 frame_width/protrude）。等距生成职责在生成器，组件只提供参数。
- **材质槽**：0 结构（`building/skybridge/frame`）、1 扶手（`building/skybridge/railing`）、2 顶棚，顺序固定；实例颜色由生成器取两端建筑墙色中间色派生（桥面略深、扶手提亮、顶棚加深）。
- **几何要求**：相邻件互相嵌入（重叠 ≥ 0.01 m）禁止共面防 z-fighting；所有件在 1 m 切片内封闭；侧面保持镂空；组件预览 Mesh 由工厂从同一组数据生成，进入目录水密与 UV/法线检查。
- **替换契约**：替换组件必须保持角色、横截面约定、六组输出、材质槽顺序，生成器、交叉求解、等距立柱与材质派生才能直接复用。

- 新增组件与 `SKYBRIDGE` 角色/几何枚举；初始版本含薄桥面（0.08 m）、双侧扶手横档、出挑顶棚，顶棚立柱沿桥长 1.6 m 等距独立布置。
- 同日契约扩展：输出分组由四组扩为六组（新增 `baluster` 栏杆立柱与 `portal` 桥端门套），桥端门洞交接时由廊桥组件在桥两端生成门套，随廊桥出现/消失与替换。
