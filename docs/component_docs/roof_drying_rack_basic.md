# 屋顶晾衣架（roof_drying_rack_basic）

## 目标

为空间足够的屋顶提供生活化晾衣架设施。

- **资源**：`assets/building_components/roof_drying_rack_basic.tres`，角色 `ROOF_DRYING_RACK`，几何 `ROOF_DRYING_RACK`，尺寸 1.7 × 1.1 × 0.85 m。
- **坐标约定**：XZ 为屋顶平面，Y 向上；屋顶锚点必须仍在轮廓内。
- **放置规则**：先按女儿墙厚度和安全间距计算内缩可用屋顶；使用完整底座与横杆的水平占地，尝试 0°/90° 两个方向；检查与检修屋的占用冲突；凹形屋顶使用多边形相交面积验证完整容纳。明显放不下的屋顶不生成，不穿围墙。
