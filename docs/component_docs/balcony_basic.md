# 小阳台（balcony_basic）

## 目标

为建筑上层立面提供小阳台组件，保证每栋建筑的生活感底线。

- **资源**：`assets/building_components/balcony_basic.tres`，角色 `BALCONY`，几何 `BALCONY`，尺寸 1.65 × 0.95 × 0.95 m。
- **坐标约定**：XY 为立面，+Z 朝外；由上层窗户和楼层高度派生。
- **装配规则**：每栋建筑的上层立面至少生成一个小阳台，允许额外阳台与晾衣杆共存；宿主窗户不合法时不生成。
