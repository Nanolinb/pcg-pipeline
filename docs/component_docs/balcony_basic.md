# 小阳台（balcony_basic）

## 目标

为建筑上层立面提供小阳台组件，保证每栋建筑的生活感底线。

- **资源**：`assets/building_components/balcony_basic.tres`，角色 `BALCONY`，几何 `BALCONY`，尺寸 1.25 × 0.45 × 0.42 m。
- **坐标约定**：XY 为立面，+Z 朝外；由上层窗户和楼层高度派生，台板位于窗台下方。
- **装配规则**：以浅花盆台替代需要入口的深阳台，包含矮栏杆、台板和植物；宿主窗户不合法时不生成。
