# 建筑生成器（building_generator）

## 目标

把建筑平面数据确定性地转成建筑实体：同一轮廓同时驱动墙体、屋顶、立面和收边。

- **生成链**：`PCGBuildingPlan → PCGBuildingFootprint（稳定 ID、平面、楼层、层高、种子、组件绑定）→ 主体挤出 Mesh → 边/面/顶点/楼层锚点 → 标准组件 Mesh 实例`。
- **确定性**：每栋建筑通过 `building + purpose` 使用独立确定性随机流，禁止调用全局随机状态；同输入语义摘要一致。
- **局部重建**：单栋编辑只重建该栋，其他建筑节点、组件和随机结果不变；整体/增量生成共享 exclusions。
- **容错**：非法轮廓、缺失组件或角色不匹配时保留上一份有效显示并返回可读错误。
- **立面求解**：入口优先预留，窗户与装饰（阳台、晾衣杆、遮阳棚、双门遮阳顶）进入同一占用与角点求解；装饰记录宿主窗户槽位；凹角两侧按组件宽度与外伸深度保留净空。
- **屋顶求解**：按女儿墙厚度和安全间距计算内缩可用区，完整水平占地验证，凹形屋顶用多边形相交面积；屋顶非矩形盖板由主体生成器直接三角化。
- **门洞交接**：廊桥结合点所在立面裁切内凹门洞（宽 = 结合点宽 + 0.3 m，深 0.45 m），墙面分条、五面洞道，主体保持封闭流形；入口被占时自动挪到最大自由区间。
- **地形**：按轮廓最高点建立水平基准面，低侧生成封闭基础；地形坡度纳入重建签名。
