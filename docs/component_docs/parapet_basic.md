# 屋顶女儿墙（parapet_basic）

## 目标

为建筑屋顶提供周边收边构件。

- **资源**：`assets/building_components/parapet_basic.tres`，角色 `PARAPET`，几何 `PARAPET`，尺寸 1.0 × 0.42 × 0.16 m。
- **坐标约定**：X 沿屋顶边，Y 向上，+Z 朝外；按实际边长缩放 X，原点为组件中心。
- **作用**：女儿墙厚度决定屋顶内缩可用区——屋顶晾衣架按女儿墙厚度加安全间距内缩后才放置。
