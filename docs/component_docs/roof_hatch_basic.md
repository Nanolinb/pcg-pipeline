# 屋顶检修屋（roof_hatch_basic）

## 目标

为屋顶提供检修出入口附属建筑。

- **资源**：`assets/building_components/roof_hatch_basic.tres`，角色 `ROOF_HATCH`，几何 `ROOF_HATCH`，尺寸 0.8 × 0.48 × 0.8 m。
- **坐标约定**：XZ 为屋顶平面，Y 向上；位于有效屋顶内部锚点。
- **避让关系**：屋顶晾衣架放置时必须避开检修屋。
