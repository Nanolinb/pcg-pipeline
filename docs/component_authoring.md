# Surface Component 组件制作手册

## 坐标与尺寸

- 统一使用米制。资产 `size` 表示组件在局部 X/Y 平面的外轮廓尺寸，`depth` 表示向外突出的深度。
- 组件原点放在吸附锚点，不要放在窗框前沿。
- 局部 `+Z` 必须朝外。`0°` 法线倾角时，局部 `+Z` 与主体表面外法线一致。
- 圆窗和方窗的窗框、玻璃、开洞体共用同一原点和朝向。

## 根部嵌入

- `root_embed` 是窗框根部向主体内部嵌入的深度，默认 `0.12m`，根面必须位于局部 `z = -root_embed`，外沿必须位于局部 `z = +depth`。
- 圆窗使用根部大、外沿小的梯形圆台。`root_flare = 0.18` 表示根面外半径比外沿大 18%，可直接用于检查正反。
- 主体包裹过渡的内圈必须连接实际大根面，而不是连接外沿或原直筒外径。
- 不要制作与主体仅共面接触的根部。布尔运算和曲面交接都需要少量实体重叠。
- 平面主体可从 `0.08～0.12m` 开始；圆柱、半球或倾斜安装时适当增加，但不能让根部穿出不需要开洞的另一侧。
- 自定义组件如果根部外形与程序窗框不同，应同时检查开洞体与根部之间是否仍有重叠。

## 主体包裹过渡

- `transition_enabled` 默认开启。过渡属于主体外观，使用主体共享材质，不是额外的窗框圈。
- 外圈逐点贴合主体曲面，内圈在主体正 Z 外侧与圆台侧壁重叠，形成实际可见的隆起；不能把可见 loft 放到负 Z 根面内部。
- 整个过渡必须是封闭实体，底部允许嵌入主体以保证水密并集。
- 过渡顶面法线使用根部 XY 径向方向与正 Z 高度计算，不得混入内外圈深度差；不得依赖整体翻转或平均法线判断正反。
- `transition_thickness = -1` 表示根据组件尺寸、当前缩放和主体曲率自动计算；非负值为显式厚度覆盖。厚度同时驱动径向宽度与自适应截面高度。
- `transition_curvature` 范围为 -1～1：0 使用直线斜面，正值使用凹圆弧，负值使用反向圆弧，-1 为完整反向曲线；不能只加宽而不生成高度。
- 过渡 CSG 与直接渲染必须共享同一 Mesh。凹形 loft 的直接渲染用于保证可见性，线框使用对应 UV2 网格。
- 合批同材质多 Surface 时必须用 `surface_index + old_index` 去重，避免跨 Surface 顶点复用错误。
- 过渡 Mesh 按锚点、倾角、缩放、密度、LOD 和参数签名缓存，未变化时不得重建。
- 过渡密度可选 25%、50%、100%、200%；LOD 0/1/2 分别使用 1、0.5、0.25 系数，环向和截面分段都参与调整。
- 拱形轮廓使用逆时针点序，下部 2/3 为矩形，上部 1/3 为椭圆弧；窗框、开洞和过渡必须使用同一轮廓并检查有向体积。
- 拖动中只更新直接预览并延迟凹形 CSG，最终融合每 0.1s 最多刷新一次，松开后立即提交，禁止每个鼠标事件全量重建。
- 邻域压缩只允许继续变小；选中的压缩组件不得自动恢复，手动缩放必须从当前实际尺寸开始并可从消失状态恢复。
- 大量编辑可开启后合并模式，只显示轻量主体/组件预览；合并选中或全部合并时才恢复 CSG 并提交最新状态。
- 密度选项按真实数值映射，1.0 对应 100%，禁止用索引近似推算造成显示与实际密度不符。
- 平面或本身已与主体良好衔接的组件可关闭过渡。曲面交接、较大组件或法线倾角较大时建议开启。
- 移动、旋转和缩放组件后应检查整个外圈，而不只检查中心点。

## Mesh 与水密要求

- 所有参与 CSG 的窗框、玻璃、主体和开洞体必须是封闭 Mesh；开放平面不能直接当作实体。
- 自定义 Mesh 使用一致的 Godot 顺时针正面绕序，不能包含零面积三角形、非流形边或重复内部面。
- 环形网格需要内外侧壁和前后端面；过渡 loft 需要底部和封口。
- 最终显示会按面夹角重建 smooth groups。制作者仍应提供正确拓扑，不能用平滑法线掩盖缝隙或开放边。
- 使用水密线框检查最终融合结果，特别检查根部、开洞和不同材质的 CSG 切面。

## UV 与共享材质

- UV0 用于表面纹理，按真实世界尺寸展开，不随组件缩放任意拉伸。
- 框架和玻璃通过稳定材质 ID 引用共享 Material Profile，不在每个实例中复制材质。
- 主体过渡和 CSG 无材质切面应继承主体材质。
- 贴图变更应更新共享材质参数，不应重建组件几何或替换组件实例。

## 性能与验收

- 程序组件应控制环向分段和过渡截面分段，避免无意义的高密度 Mesh。
- 最终显示使用空间 Chunk 与共享材质合批；自定义资产不得绕过该显示管线。
- 至少在平面、圆柱侧面和半球上各验证一次：放置、跨面拖动、法线倾角、用户缩放、邻域缩放、消失和恢复。
- 对曲面组件额外验证过渡开关、厚度、弧度以及线框下的封闭性。
