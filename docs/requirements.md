# PCG 工具需求与工程结构

## 工程结构
- 根目录 `project.godot`：Surface Component PCG，保留表面组件、吸附与实体融合功能。
- `PipeWeaver/project.godot`：PipeWeaver · 管道 PCG，独立管道工具，禁止与组件版共用主脚本。
- 两个工程的 `.godot/` 缓存均不进入 Git。

## Surface Component PCG 当前需求基线
- 组件必须从资产库拖放到平面墙或半球圆柱组合主体，预览交叠时高亮主体。
- 右侧主体由真实圆柱与同半径上半球 CSG 并集构成，包含独立实体和轮廓。
- 放置后可沿原主体表面拖动，并从圆柱侧面连续跨赤道到半球，组件默认 0° 遵循表面法线。
- 选中组件提供角度与等比缩放手柄，并提供法线倾角数值输入。
- 最终缩放 = 用户等比缩放 × 邻域自动缩放；不同主体不得互相影响。
- 主体与组件使用封闭 CSG 融合，支持水密线框检查。
- CSG 最终显示网格必须按面夹角重建 smooth groups：曲面连续平滑，开洞与端面保留硬边。
- 水密线框直接显示最终融合网格的三角边线，不依赖视口调试绘制。
- 当前版本为 v0.5.0，版本写入根目录 `project.godot`。

## 版本规划
- 使用语义化版本 `主版本.次版本.修订号`。
- 新功能且向后兼容时提升次版本；缺陷修复提升修订号；不兼容变更提升主版本。
- 每次需求或缺陷修改同步更新本文件与 `docs/changelog.md`。
- 每次修改单独提交，提交信息采用 `type(scope): summary`，不得在提交中混入无关工程文件。

## PipeWeaver 当前需求基线
- 在同一立体表面通过起止点或 Paint 创建管道。
- 起止点允许位于两个不同主体，完整比较候选连接，以两侧表面路径与跨接距离之和最短为准。
- 双主体路径逐点记录所属碰撞体，平滑投射、拖动和角度设置使用对应主体。
- 连续管体、自动接头、法线正确、按世界尺度平铺 UV。
- 直径分段及独立变径。
- 中间控制点拖动、追加、插入、删除和撤销。
- Paint 点击现有路径直接插入控制点。
- Paint 允许在同一主体的多个面之间一笔绘制；法线变化超过 45° 时自动识别棱边。
- 棱边默认生成硬转角与接头，初次生成即体现主体 90° 转折，可后续改为平滑弯头。
- 每节点平滑/硬直角、路径内夹角及 2～32 段独立圆角细分。
- 完成当前管道后冻结；新建下一根使用独立 Pipe_XXX 节点，旧管体不得被覆盖。
- 所有管道均保存完整 PCG 快照，可重新选中并恢复控制点和参数继续编辑。
- 选择模式支持单选、Shift/开关多选及全选；恢复编辑限单选。
- 多选管道可分别合并为固定 Mesh，保留材质、变换和层 2 拾取，PCG 数据用于之后恢复。
- 每节点独立离墙偏移，并提供蓝色 Z 轴手柄和数值输入。
- 最终离墙量 = 当前管道全局表面间隙 + 节点独立偏移。
- 操作面板左右留白 10px，默认字号 15、标题 20、提示 14。
- 完成/新建按钮位于右侧首屏。

## 工作方式约束
- 新需求不得为每次验证另开 Godot 窗口；只重用一个 PipeWeaver 实例。
- 版本对比通过 Git 提交，不通过多窗口并存。
- 每次需求变更同步更新 `docs/requirements.md` 与 `docs/changelog.md`。
