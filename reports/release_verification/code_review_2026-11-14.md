# 代码检查与重复整理验收报告

日期：2026-11-14

## 检查范围

覆盖 L0/L1 资产、表面组件、PipeWeaver、建筑白盒与廊桥。检查依赖方向、重复实现、状态泄漏、硬编码契约、撤销/保存/局部重建和性能影响。

## 主要发现与处理

- 建筑入口 bay 公式与实际窗口不一致，整体生成忽略 exclusions，标高和 auto_lift 存在跨构建状态泄漏：已修复并补回归。
- 带 connector 的建筑切分可能使 plan 无法恢复：已增加安全拒绝与提示。
- 占用推导在旋转资产上不一致：已统一核心推导并支持用户余量。
- 哈希存在不稳定的旧实现：已统一规范化序列化。
- 网格、表面数学、类解析和 JSON 文档加载存在重复实现：已抽取纯函数共享件。
- 建筑工作台存在第三套撤销历史：已迁移到统一命令历史并拆分平面几何。
- PipePresetCatalog 缺少目录错误、重复 ID 和真实应用覆盖：已补齐。

## 隔离边界

- 不合并两个主程序。
- 不统一 CSG、编辑器业务或领域资源。
- 路径扫掠只共享采样原语，不合并 PipeWeaver 与廊桥坐标架策略。

## 用户验收建议

- 检查建筑入口在廊桥遮挡后仍存在且落在真实开间。
- 连续构建不同标高建筑，确认没有上一栋标高残留。
- 尝试切分带结合点建筑，应提示先移除连接且平面不变。
- 连续拖动同一建筑，一次撤销应回到拖动起点。
- 应用不同管道预设，确认网格和材质按预设变化。
- 检查 `PipeWeaver/addons/pcg_shared` 链接和 `tools/check_architecture.py` 结果。
