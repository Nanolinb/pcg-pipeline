# PCG 管道 · 建筑群与管道程序化生成

基于 Godot 的程序化生成（PCG）工程：平面驱动的建筑群编辑与生成、表面组件编辑器插件、PipeWeaver 管道工具，以及面向生产闭环的资产标准化与共享内核。

## 现有功能

### 建筑平面工作台（`scenes/building_workbench.tscn`）
- 顶视图平面编辑：顶点拖动、面岛新增/切分/删除、整栋平移、相交/相接轮廓融合（保留主选中 ID 和最高楼层）。
- 视图操作：空白/右键/中键平移，25%～800% 光标中心滚轮缩放与一键适配；独立原生细节窗口共享选择、模式、数据和编辑历史。
- 参数编辑：楼层、层高、细节种子（修改后立即自动应用）、墙面颜色；斜坡地形基准面与低侧封闭基础。
- 多选与融合：Shift+单击多选，融合严格使用显式选中集合，不满足条件时给出原因提示。
- 新建建筑：确定性随机流生成尺寸、矩形/L 形轮廓、楼层、种子和颜色，按密度评分在建筑群外围及空隙选址。
- 修复选中建筑：只重建当前建筑，重排门窗并报告阻止的立面组件数量。

### 建筑生成器与标准组件（`scripts/building/`、`assets/building_components/`）
- 生成链 `PCGBuildingPlan → Footprint → 主体挤出 Mesh → 锚点 → 标准组件实例`；同一份轮廓驱动墙体、屋顶、立面和收边。
- 12 份标准组件：木框窗、入口门、双门带遮阳顶、女儿墙、墙角立柱、布艺遮阳棚、小阳台、屋顶检修屋、屋顶晾衣架、窗外晾衣杆（空杆/有衣物）、标准廊桥。
- 确定性：每栋建筑独立随机流；单栋编辑只重建该栋；非法轮廓保留上一份有效显示。
- 立面求解：入口优先预留，门窗与装饰统一占用/角点求解，凹角净空，屋顶完整占地验证。
- 组件扩展规则见 `docs/building_component_authoring.md`。

### 廊桥连接系统
- 结合点（建筑 + 立面边 + 边内位置 + 楼层）与路径定义（节点 + 转弯强度 + 自动抬升）持久化为 plan 生成数据。
- 三次 Hermite 样条扫掠标准组件横截面成桥；起止楼层不同自动生成坡道；立面自动避让并重排开窗；结合点立面裁切内凹门洞、桥端门套交接。
- 交叉求解：高度重叠超过 60% 合并为 cross 结构，否则自动垂直错开保留 0.6 m 净空。
- 主视图编辑：屏幕投影拾取 + 射线-平面拖拽的横截面握把（左右拖宽、顶部拖高）与各节点贝塞尔手柄（tension 推导、拖动转显式）；门洞与门套宽高跟随廊桥截面调整。

### PipeWeaver 管道工具（`PipeWeaver/`）
- 表面起止点寻路与 Paint 绘制，支持跨面一笔绘制、跨双主体最短路径、45° 法线突变自动棱边。
- 控制点编辑：拖动/插入/删除、每节点角度、硬直角/圆角、`wall_offset` 离墙偏移、撤销。
- 程序 PBR 平铺纹理、每管 UV2 AO 烘焙、8 m Chunk × 材质合批固定 Mesh，冻结后保留 PCG 数据可重选编辑。
- 管道预设资源库：5 种工业预设，替换保持路径与控制点不变。

### Surface Component 编辑器插件（`addons/surface_components/`）
- 平面/圆柱/半球圆柱主体，拱/圆/方窗拖放吸附，角度与等比缩放手柄。
- 主体包裹过渡（厚度自适应、弧度 -1～1）、实时 CSG 融合或后合并轻量预览、8 m Chunk 合批、水密线框。
- L0 资产任务工作台与 v0.16 L1 资产标准化窗口（几何验收、校准、试装、白盒/碰撞/LOD、JSON 清单原子发布）。

### 共享内核（`addons/pcg_shared/`）
- 稳定 ID、格式迁移、编辑命令、确定性随机、重建签名、原子保存、表面宿主接口；两个工程通过链接共享同一物理来源。
